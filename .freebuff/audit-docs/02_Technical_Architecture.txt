PROJECT
SamudraTrace AI — Sentinel-1 oil-spill detection, bidirectional drift reconstruction and explainable AIS vessel attribution for Smart India Hackathon 2026.

Prepared for a CSE Core + AI/ML team  |  Zero-cost MVP  |  Version 1.0

1. Architecture decision
Use a local-first modular monorepo. FreeBuff generates the Next.js/TypeScript experience. A Python FastAPI service owns all scientific computation. SQLite stores case metadata; files hold large geospatial artifacts. The system uses prepared regional data and lightweight ONNX inference so the user’s Ryzen 7 laptop can run the judge demonstration without a discrete NVIDIA GPU.

4. Processing sequence
POST /cases creates an investigation and immutable case directory.
POST /cases/{id}/sar validates metadata and registers the scene.
POST /cases/{id}/detect launches preprocessing, classification, segmentation and geometry.
POST /cases/{id}/drift executes backward and forward ensembles with stored seeds.
POST /cases/{id}/ais validates, cleans and segments trajectories.
POST /cases/{id}/attribute filters candidates and calculates component evidence.
GET /cases/{id}/map assembles GeoJSON layers; GET /cases/{id}/report creates the evidence package.

8. Data and model contracts
Raster input: GeoTIFF/COG with CRS, affine transform, nodata, acquisition UTC, scene ID and polarization.
Detection output: probability raster, thresholded mask, confidence, model/preprocessing versions and review state.
Environmental input: NetCDF with coordinate axes, UTC time, variable names, units, depth and source metadata.
AIS input: MMSI, UTC timestamp, latitude, longitude, SOG, COG and optional vessel type/name; original rows retained.
Map output: WGS84 GeoJSON with stable layer IDs, timestamps and style hints.
Evidence manifest: hashes, source licenses, parameters, software/model versions, warnings and created timestamps.

11. Engineering rules
API schemas are written before FreeBuff screen generation.
Scientific code never executes inside the browser or FreeBuff-generated client.
Raw inputs are immutable; derived artifacts always point to their parents.
Every operation is retry-safe or protected by an idempotency key.
No hidden global state; settings come from validated configuration.
Large files are streamed, size-limited and processed outside the request thread.
Advanced models remain behind stable interfaces and cannot block the baseline MVP.
