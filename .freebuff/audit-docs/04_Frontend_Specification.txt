4. Spacing and layout
Use an 8 px spacing grid: 4, 8, 12, 16, 24, 32 and 48 px.
Desktop shell: 240 px left navigation, flexible map workspace, 360 px evidence drawer.
Tablet: collapsible navigation and overlay evidence drawer.
Mobile: bottom navigation; map first; full-screen drawers for layers, timeline and candidates.
Maximum reading width for report text: 760 px.
Cards: 12 px radius, 1 px neutral border, restrained shadow, 16-20 px padding.
Minimum touch target: 44 x 44 px; visible keyboard focus ring.

7. Case workspace behaviour
Top bar shows case name, observation time, save state and export status.
Left stage rail shows Data, Detection, Drift, AIS, Attribution and Report with completion states.
Map remains the primary surface; drawers must not permanently reduce it below usable width.
One global time slider controls particle layers and AIS track replay.
Legend explains every colour, contour percentage and confidence value.
Selecting a candidate highlights its track and corresponding source-corridor intersection.
Warnings remain visible until resolved or explicitly acknowledged.
Every generated result links to model/data version details.

9. Accessibility
WCAG 2.1 AA contrast for text and essential graphics.
Semantic headings, landmarks, buttons and form labels.
Keyboard-operable map alternatives: layer list, time controls and candidate table.
Focus order follows visible order; focus is restored after closing drawers.
Status uses icon and text, never colour alone.
Animations respect prefers-reduced-motion; particle replay can pause.
Charts and map-derived values have textual summaries.

11. API and integration specification
[TABLE]
Integration
Request/use
Expected result and UI handling
FastAPI case API
JSON/multipart through typed client
Validated case/resource objects; map field errors inline.
Job status
Poll /jobs/{id} every 1-2 seconds while active
progress 0-100, stage, safe error, result refs; stop on terminal state.
Map layers
GET /cases/{id}/map?layers=&time=
GeoJSON with layer IDs/timestamps; ignore unknown optional properties.
Report export
GET /cases/{id}/report?format=
Download blob; show progress and checksum.
MapLibre/Leaflet
Render OSM/local base plus GeoJSON
Base-map failure must not hide evidence layers.
FreeBuff
Generate/export Next.js UI against mock OpenAPI contract
No model execution, secret storage or scientific calculation.

12. FreeBuff build instructions
Create the responsive application shell, routes and reusable design-system components first.
Use realistic mock JSON matching the documented API schemas.
Build the case workspace and global timeline before decorative dashboard widgets.
Export/sync the repository, then keep Python in a separate /backend directory.
Replace mocks endpoint by endpoint without changing component contracts.
Add loading, empty, error, unauthorized, offline and no-candidate states for every screen.
Do not ask FreeBuff to train a model, run OpenDrift, parse GeoTIFF/NetCDF or decide vessel responsibility.
