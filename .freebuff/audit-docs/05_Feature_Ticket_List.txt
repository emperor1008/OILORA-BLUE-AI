1. How to use this document
Build tickets in the listed order. Give one ticket at a time to FreeBuff or another coding tool. Require it to inspect the repository, preserve existing behaviour, implement only the ticket scope, run the stated tests and report changed files. Must-have tickets define the demo MVP; should-have and nice-to-have tickets cannot delay it.
[TABLE]
GLOBAL CODING RULE
No dummy success paths. Mock data is allowed only behind an explicit demo fixture and must match the real API contract. Never hide failed scientific processing by returning fabricated results.
