# Oilora Blue AI — Geospatial runtime (SAR preprocessing, raster IO)
# Installed on top of requirements.txt when SAR preprocessing starts.

# Windows. Create a clean 3.12 environment before installing:

#   .venv312/Scripts/python.exe -m pip install -r requirements.txt -r requirements-dev.txt -r requirements-geo.txt
